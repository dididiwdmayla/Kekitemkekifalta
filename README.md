# kekitemkekifalta

App Android de estoque de casa, feito para um casal.

- **kekitem**: o que tem em casa. O app aprende quanto tempo cada coisa dura e avisa o que está acabando.
- **kekifalta**: o que precisa comprar, com sugestões e um modo mercado organizado pelos corredores.

## Instalar e atualizar

1. No celular, abra o GitHub no navegador já logado na sua conta (o repositório é privado).
2. Baixe o APK: <https://github.com/dididiwdmayla/Kekitemkekifalta/releases/download/latest/kekitemkekifalta.apk>
3. Abra o arquivo baixado e permita "instalar apps desta fonte" quando o Android pedir.

Para atualizar, baixe de novo pelo mesmo link e instale por cima: os dados continuam.
Cada merge na `main` gera um APK novo nesse link (leva uns 5 minutos).

## Passar os dados para o outro celular

Ajustes → Backup → **Exportar** gera um arquivo JSON. No outro celular: Ajustes → Backup → **Importar**.
